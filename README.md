# 小红书笔记转化分析看板

用于分析小红书笔记从曝光、阅读、商品点击到支付成交的转化表现，支持内容运营、店铺运营和投放运营三个板块。

## 使用方式

在项目目录执行：

```powershell
python dashboard.py
```

脚本会读取店铺CSV并重新生成：

- `index.html`：可直接用浏览器打开的看板页面
- `dashboard_data.json`：生成后的分析数据

## 三店铺数据

每个店铺使用独立数据文件：

| 店铺 | 数据文件 | 当前状态 |
| --- | --- | --- |
| 鲜水湾 | `data/stores/store-1/notes_gpm.csv` | 已接入当前真实数据 |
| 琪琪生鲜 | `data/stores/store-2/notes_gpm.csv` | 等待替换真实数据 |
| 玺牛生鲜 | `data/stores/store-3/notes_gpm.csv` | 等待替换真实数据 |

三个CSV沿用相同字段结构。替换店铺数据后重新运行 `python dashboard.py` 即可生成对应分析。

页面顶部可以切换店铺。切换后，KPI、图表、排行、表格以及日期、账号、商品和笔记类型筛选均只使用当前店铺数据。

## 当前功能

### 内容运营

- GPM排行榜、曝光量排行榜和内容行动队列
- CTR、CVR和四象限素材分析
- 笔记生命周期与内容类型表现分析
- 官方流量扶持候选表：近15个自然日内发布且阅读量严格大于200
- 发布时间超过180天的素材使用 `⚠️` 标记

### 店铺运营

- 商品效率榜单
- 转化漏斗
- 账号×商品矩阵
- 商品效率与规模错位分析

### 投放运营

- 每日支付趋势
- 推广状态观察
- 基准对比

## 数据口径

- `GPM = 支付金额 ÷ 曝光量 × 1000`
- 零成交诊断只统计：`支付金额 = 0 且 商品点击次数 > 0`
- 商品点击次数为0的笔记不进入零成交诊断，但仍保留在其他内容分析中
- 官方流量扶持候选按浏览器当前日期计算15日窗口，不代表平台已经实际给予流量扶持
- 超过180天素材使用浏览器当前日期计算，不使用数据集最新日期
